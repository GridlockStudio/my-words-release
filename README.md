# My Words: downloads

Test builds of the **My Words** vocabulary app for Android. This repository holds downloads only; it contains no source code.

- Latest build: see [Releases](../../releases).
- Install: download the `.apk` from the newest release on your phone, open it, and allow the install when Android asks.

My Words lets you look up a word, hear it, save it, and listen back to your list in nine languages, including Persian and Dari.

These are **beta test builds**. They can contain mistakes, and some texts are still placeholders.
